# Changelog

All notable product changes are documented here.

## Unreleased

### Added

- Evidence-based review queue on the daily desk and in the learning center.
- Review tasks with due state, effort estimate, mastery context, and explicit completion evidence.
- Account-synced 7-day learning sprint with an editable weekly goal, daily effort target, and visible completion evidence.
- Source-grounded evidence notebook for personal examples, boundaries, open questions, autosave, and Markdown export.
- Real email authentication, HTTP-only sessions, and account-scoped learning records.
- Server-side OpenAI-compatible model proxy and deployment capability reporting.
- CI verification for tests and production builds.

### Improved

- Story-first lessons now reveal and formally decode concepts before interaction.
- Responsive desktop and mobile layouts.
- Daily desk and learning center now share one continuous sprint state across sessions and devices.
- Trust copy now distinguishes demo data from real personalized scheduling.
- Repository documentation for architecture, deployment, product decisions, design, contribution, and security.
